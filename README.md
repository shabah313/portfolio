# S.M.Aa | Personal Portfolio

A personal portfolio website for **Seyed Mahdi Alavi** (web developer), showcasing web design projects, certificates and contact details.

🌐 **Live website:** [sm-aa.ir](https://sm-aa.ir)

## About

The site is written in Persian (RTL) with a dark, luxury look: black background, gold accents and the Vazirmatn font. It is built from scratch with plain HTML, CSS and JavaScript, with no frameworks.

## Sections

- **About me:** short introduction and skill badges
- **Projects:** sample websites (online shops, restaurant, cafe, bookstore, watch gallery and more) with a preview modal
- **Certificates:** web design (HTML, CSS, JS), PHP and Python
- **Contact:** message form, email and social links

## Tech stack

- HTML5
- CSS3 (responsive layout)
- JavaScript (preview modal, interactions)
- Font Awesome icons
- PHP (on the server side of the live site)

## Project structure

```
portfolio/
├── index.html          # main page
├── style.css           # styles
├── script.js           # main scripts
├── preview-modal.js    # project preview modal
└── imag/               # images
```

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/shabah313/portfolio.git
   ```
2. Open `index.html` in your browser.

No build step or installation is needed.
